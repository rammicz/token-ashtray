# YouTube author link icon

YouTube and the YouTube icon are trademarks of Google LLC. The icon identifies
the destination of the author’s video link; it does not imply endorsement.

Source: [YouTube brand resources](https://brand.youtube/youtube-logo/), retrieved
2026-10-24. The page links the official [Core YouTube icon archive](https://www.gstatic.com/marketing-cms/89/d9/cf95c4f345709f4998dc581221b0/youtube-icon.zip).
The retained `youtube-icon.png` is the unmodified archive member
`YouTube_Icon/Digital/01 Red/yt_icon_red_digital.png` (1255×1075 RGBA).
`youtube-icon-ui.png` is a uniform one-fifth resize (251×215), using Pillow
`Image.LANCZOS`. No crop, recoloring, distortion or added mark is applied.
Transparent clear space is preserved. The unread dot is a separate UI indicator
outside the visible mark. Exact file and archive hashes are recorded in
`provenance.json`. The brand page specifies the current red as #FF0033.

These brand assets are used subject to YouTube’s brand guidelines and are not
licensed under this application’s software license.
